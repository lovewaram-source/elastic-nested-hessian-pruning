# 维护者发布说明

本页面向整理源码、打包和发布GitHub版本的维护者。实验使用者从 [README](../README.md) 和 [INSTALL](../INSTALL.md) 开始即可。

## 生成精简包

在维护工作目录运行：

```bash
python scripts/export_github.py --destination dist/github --zip
```

工具使用明确入口清单并补齐本地Python依赖，保留必要的内核、测试、方法文档和原始许可证；排除模型、数据、原始结果、日志、仓库历史、本地归档和预览文件。

目标目录或ZIP已存在时会拒绝覆盖。保留旧版本并选用新的目标目录，例如`dist/github-next`，或者由维护者明确归档旧包后再生成。不要为重新生成源码包删除原始实验结果。

导出的`SOURCE_MANIFEST.json`包含每个源文件的SHA256。发布前核对清单、文档链接和压缩包，运行轻量测试与完整小模型数值测试。当前已有的完整数值测试需要在具备可用PyTorch环境的机器执行；静态检查不替代数值验证。

## 上传范围

将生成目录中的内容作为公开仓库根目录。`.local_archive/`是维护工作目录中的可恢复历史记录，不属于公开包。请保留MIT许可证及上游来源说明。

本地GitHub风格预览用于检查排版，并不表示已经上传、发布或通过GitHub CI。预览资源不作为算法运行依赖，不加入`requirements.txt`。
